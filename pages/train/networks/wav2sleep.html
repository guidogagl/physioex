Wav2Sleep (Carter & Tarassenko, 2024)#

wav2sleep stages sleep from any subset of cardiorespiratory signals (ECG, PPG, abdominal and thoracic effort) recorded over a whole night. Each signal has its own encoder; per-epoch embeddings are mixed across the available signals with attention and then across epochs with a dilated CNN. A signal that is missing is masked, so one model serves every combination of inputs it was trained on.

  • Paper: wav2sleep: A Unified Multi-Modal Approach to Sleep Stage Classification from Physiological Signals, ML4H 2024, arXiv:2411.04644.

  • Authors’ code and weights: joncarter1/wav2sleep (GitHub), joncarter/wav2sleep and joncarter/wav2sleep-eog (Hugging Face), MIT.

  • physioex class: physioex.models.wav2sleep:Wav2Sleep (a clean re-implementation; the original checkpoints load with strict=True after key conversion).

Quick start#

from physioex.data.datasets import get_dataset
from physioex.models import load_from_pretrained
from physioex.train import replication as rep

model = load_from_pretrained("wav2sleep", verbose=True)   # downloads from the Hub

data = get_dataset("mesa")(
    channels=["ECG", "PPG", "ABD", "THX"],
    pipelines="wav2sleep",          # the authors' preprocessing
    sequence_length=0,              # one item = one whole night
    label_transform="aasm4",        # W, Light (N1+N2), Deep, REM
    trim_excess_wake=False,
)
test = data.get_splits(split="wav2sleep")[2]
for subject, signals, labels, metadata in rep.iter_nights(data, test[:1]):
    stages = model.predict_night(signals)   # (n_epochs,) int64 in 0..3

predict_night accepts any subset of the keys ECG, PPG, ABD, THX (EOG-L, EOG-R for wav2sleep-eog); keys it does not know are ignored. Nights longer than 10 h are truncated to 1200 epochs.

Inputs and preprocessing#

The wav2sleep preset reproduces the authors’ ingestion: ECG and EOG are converted to millivolts, PPG and respiratory effort are scaled by their physical range; each signal is linearly interpolated onto a grid of 1024 samples per 30-s epoch (256 for ABD/THX, 4096 for EOG), padded with zeros or truncated to 10 h, and z-scored over the whole grid. The checkpoints use four classes (label_transform="aasm4").

Replication#

examples/pretrained/wav2sleep/verify.py evaluates the checkpoint on the paper’s test lists (get_splits(split="wav2sleep"), all visits of SHHS, MROS and WSC) with the paper’s metric, pooled Cohen’s kappa, and compares with Table 6. As in the authors’ evaluation, test nights without any N1, N3 or REM epoch are left out, and a flat PPG is treated as absent.

The labels and the preprocessed ECG were checked against the authors’ own pipeline: the labels match on every test night of SHHS, MROS, MESA and CCSHS, and the ECG input matches (r = 1.0000, per-night kappa within 0.0004). With the public checkpoint, pooled kappa minus Table 6 is:

Training#

physioex does not ship a training script for this model. The authors’ recipe is summarised in examples/pretrained/wav2sleep/TRAINING.md.

Bases: Module

Model for sleep staging.

This model is used to classify sleep stages from time-series inputs.

The network works as follows:

  1. Each input signal is passed through a signal encoder.

  2. Embeddings are mixed for each sleep epoch level.

  3. Sequence model mixes epoch features.

  4. Classifier is applied to output features.

predict_night(signals, metadata=None)[source]

Classify one whole night, already preprocessed by the wav2sleep preset.

Parameters:

  • signals (dict[str, np.ndarray]) – Mapping of signal name (ECG, PPG, ABD, THX, …) to a (L, T_e) float array of one night, with T_e = SAMPLES_PER_EPOCH[signal] samples per 30-s epoch. Keys the model does not know are ignored; known keys missing from signals are passed to the model as absent. The night is zero-padded (or truncated) to the model’s fixed 1200-epoch (10 h) grid only when L differs from 1200, matching the authors’ padding/truncation of shorter/longer nights.

  • metadata (dict | None) – Unused (kept for a common interface with the other cardiorespiratory models).

int64 class indices of shape (L,) in the model’s own class order ([W, N1+N2, N3, REM] for the 4-class model). Runs under torch.no_grad() in eval mode, batch of one, on the model’s current device.
