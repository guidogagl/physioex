physioex.models.jones_ecg.JonesECGNet#

class physioex.models.jones_ecg.JonesECGNet(variant='primary', n_classes=5)[source]#

Bases: Module

ECG-only sleep staging network of Jones, Itti & Sheth (2024).

Parameters:

  • variant (str) – one of VARIANTS (default "primary").

  • n_classes (int) – number of sleep classes (5: W, N1, N2, N3, REM).

Forward input:

  • x: (B, L, 1, 7680) or (B, L, 7680) float32 ECG, 256 Hz, in [-1, 1].

  • additional: (B, L, 4) auxiliary features; if None it is built with build_additional(), filling the columns the variant was not trained with by standard-normal noise.

  • padding_mask: (B, L) or (B, L, 1) bool/float, 1 = real epoch; default all ones.

Forward returns (B, L, n_classes) log-probabilities over [W, N1, N2, N3, REM].

static build_additional(n_epochs, variant, age=None, sex=None, midnight_offset=None, generator=None)[source]#

Build the (n_epochs, 4) auxiliary-feature matrix for one night.

Columns: [sex (0=F, 1=M), age/100, night_e (−1→1 across the night), midnight_e]. For cyclic variants the last two columns are replaced by (cos t_e, sin t_e) with t_e = 2π(e/2880 + midnight_offset mod 1). Columns the variant was not trained with (see VARIANTS) are filled with standard-normal noise drawn from generator: one draw per epoch per column, except demographics which are drawn once per night (size 2) and repeated over the epochs.

Raises:

ValueError – if age, sex or midnight_offset is missing for a variant that was trained with it.

Parameters:

predict_night(signals, metadata=None)[source]#

Classify one whole night, already preprocessed by the jones_ecg preset.

Parameters:

  • signals (dict[str, np.ndarray]) – Mapping of signal name to a (L, 7680) float array of one night (256 Hz, 30-s epochs, in [-1, 1]); the night’s "ECG" channel is required. Unlike the fixed-grid models, JonesECGNet accepts any number of epochs, so the night is not padded or truncated here.

  • metadata (dict | None) – optional dict with "age" (years), "sex" ("M"/"F") and "recording_start" (datetime.time). The auxiliary features are built with build_additional() for the model’s variant; a missing value that the variant was not trained with (see VARIANTS) is filled with the variant’s noise fallback, with one warning per missing key.

Returns:

int64 class indices of shape (L,) in AASM 5-class order [W, N1, N2, N3, REM]. Runs under torch.no_grad() in eval mode, batch of one, on the model’s current device.

Return type:

np.ndarray
