physioex.train.replication#

Library support for replicating published cardiorespiratory results.

The three integrated cardiorespiratory sleep-staging networks (Wav2Sleep, SleepPPG-Net and the ECG-only network of Jones et al.) report their headline numbers as Cohen’s kappa computed in two different ways:

  • pooled — one confusion matrix over every scored epoch of every recording (Wav2Sleep’s kappa_T, Jones’ overall_kappa);

  • median record — one kappa per recording, then the median across recordings (SleepPPG-Net, Jones’ headline number).

This module provides the plumbing to recompute those numbers on whole nights and check them against the values printed in the papers:

  • iter_nights() pulls whole nights (preprocessed signals + aligned labels + metadata) out of a BasePhysioDataset built in whole-night mode (sequence_length <= 0);

  • align() trims a prediction and its label array to a common length the way the authors’ inference code does (see the docstring);

  • evaluate() wraps physioex.train.metrics.pooled_kappa() and friends;

  • load_paper_metrics() / check() / format_table() read the paper’s claimed values (a small JSON file), compare them with the measured ones and render a fixed-width table.

No GPU or data access happens at import time.

physioex.train.replication.align(pred, labels)[source]#

Cut prediction and labels to their common length.

Whole-night models with a fixed input grid (Wav2Sleep, SleepPPG-Net: 1200 epochs) produce predictions for padded epochs when the night is shorter than the grid, and the authors’ inference drops the tail labels of nights longer than the grid. Both effects leave pred and labels at different lengths; cutting both to min(len) recovers the epochs that are scored and predicted alike.

Parameters:

  • pred (ndarray) – prediction array, (L_p,) class indices (any length).

  • labels (ndarray) – label array, (L_l,) class indices.

Returns:

(pred_aligned, labels_aligned, n_dropped) where the first two have shape (min(L_p, L_l),) and n_dropped is the number of labelled epochs that were dropped (max(0, L_l - min(L_p, L_l))) so callers can report it.

Return type:

tuple[ndarray, ndarray, int]

physioex.train.replication.has_scoring_issues(dataset, subject_id)[source]#

True when the night has no N1, N3 or REM epoch in its raw AASM labels.

wav2sleep’s ingestion marks such nights as .issues (recordings scored sleep/wake only, with N2 as the sole sleep class) and its per-dataset test evaluation leaves them out (exclude_issues=True). The check reads the labels before any label_transform, since aasm4 merges N1 into Light.

physioex.train.replication.iter_nights(dataset, subject_ids)[source]#

Yield one entry per whole night of the given subjects.

The dataset must be built in whole-night mode (sequence_length <= 0); in that mode item index i is exactly subject i (see BasePhysioDataset._get_recording_item).

Parameters:

  • dataset (BasePhysioDataset) – a BasePhysioDataset instance (whole-night mode).

  • subject_ids (Sequence[str]) – subject ids to iterate over, in any order.

Yields:

Tuples (subject_id, signals, labels, metadata) where

  • signals maps the requested channel name (channel_info[key] ["request"], e.g. "ECG"; the item key such as "ECG_0" when no request is recorded) to a (L, T_e) float32 array of the (preprocessed) whole-night signal. Channels the subject lacks (available=False, zero-filled by the dataset) are left out;

  • labels is the (L,) int64 label array in the dataset’s label transform (e.g. aasm4: W=0, Light=1, Deep=2, REM=3; -1 unscored), aligned with the signals;

  • metadata is the return value of dataset.subject_metadata(subject_id) when the dataset provides that method, else {}.

Return type:

Iterator[tuple[str, dict[str, np.ndarray], np.ndarray, dict]]

physioex.train.replication.load_paper_metrics(path)[source]#

Read the paper’s claimed results from a JSON file.

The file has the top-level keys "model", "source", "metric", "tolerance" and "targets" (a list of objects with keys dataset, condition, value and optional metric, tolerance, assert (bool, default true), requires, note). A target’s optional metric/tolerance/assert override the top-level ones.

Parameters:

path (str | Path) – path to the JSON file.

Returns:

(header, targets) where header is the top-level dict without "targets" and targets the list of PaperTarget.

Return type:

tuple[dict, list[PaperTarget]]
