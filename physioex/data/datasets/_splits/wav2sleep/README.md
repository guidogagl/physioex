# wav2sleep splits

Session-id lists copied verbatim from `src/wav2sleep/data/splits/` of
https://github.com/joncarter1/wav2sleep (commit 278e304, MIT License,
Copyright (c) Jonathan F. Carter). Used to reproduce Carter & Tarassenko (2024),
"wav2sleep: A Unified Multi-Modal Approach to Sleep Stage Classification from Physiological Signals",
arXiv:2411.04644. Ids are EDF stems as distributed by NSRR. `census` = the census-balanced set of
Jones et al. (2024), 500 val + 500 test ids drawn from ccshs/cfs/chat/mesa/wsc; `mros` is test-only.
