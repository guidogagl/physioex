# SleepPPG-Net replica split (MESA)

`mesa/test.txt` lists the 204 MESA test recordings used by the third-party
SleepPPG-Net replica (`SPPPPGNet` 0.1.4, weights on Hugging Face
`sleep-is-all-you-need/SPPPPG-Net`). They are the first 204 entries of
`dataversion.recordIds` in the package's `config.yaml` (split `test: 0:204`),
in the original order. The replica's authors state that this is the MESA test
set of Kotzen et al. (2023). Only the record ids are reproduced here.
